AI TOOL RULES — Forensic Council

Before any edit, every AI tool (Antigravity, opencode, Claude.ai, ChatGPT,
Gemini, MiniMax, anything) MUST read in order:

1. AGENTS.md
2. PROJECT_HANDOFF.md
3. The specific file being edited

Hard rules:
- Do not edit .env, .env.example, package-lock.json, or uv.lock without
  being told the exact line to change.
- Do not change Python version, Debian base, or Node version in any Dockerfile.
- Do not collapse USE_REDIS_WORKER and DOCKER_USE_REDIS_WORKER.
- Do not change outputFileTracingRoot in next.config.ts.
- Do not move pendingFileStore from memory to localStorage/sessionStorage.
- Do not remove `:?` strict-required syntax from docker-compose env vars.
- Do not edit files in PROJECT_HANDOFF.md's "Files Not to Touch Casually" list.
- Do not skip the migration container's `alembic upgrade head` step.

After any edit, run AT LEAST:
  ./scripts/verify_project.sh static

Paste the OUTPUT of that command back into the chat so the human can confirm
no regression. If the script fails, undo the change and report the failure.
